# v0.8 acceptance report

Tag: `v0.8.0` (`e5a7f3c`), 2026-05-22.
Built and tested on: Windows 10 Pro 10.0.19045, Node v24, PowerShell 7.x.

Filesystem-MCP parity sweep + the wave-2c architectural closure. Full detail in
CHANGELOG `[0.8.0]` and spec amendment §AB.

## What shipped

Tool surface **37 → 39 (+2)**; two existing tools extended (non-breaking).

- **`directory_tree`** — recursive JSON tree `{ root, total_nodes, truncated }`.
  Args `path`, `max_depth` (1..8, default 3), `exclude_patterns` (basename
  globs). 10 000-node hard cap; `truncated_reason: 'max_depth' | 'max_nodes'`.
  Symlinks walked as files, never followed.
- **`read_media_file`** — base64 reader for binary media (image/audio/video/PDF),
  the companion to text-only `read`. Streams in 64 KB chunks; returns
  `{ base64, content_type, bytes_read, truncated }`. Default 16 MB cap; oversize
  without `max_bytes` → ETOOLARGE.
- **`read`** gained `head: N` / `tail: N` (mutually exclusive with `range` and
  each other; two → EINVAL).
- **`list`** gained `sort_by: 'name' | 'size' | 'mtime'` (omit → walk order,
  unchanged contract).
- **Wave 2c refactor:** all 39 `register*Tool` calls take `(server, ctx)`;
  `createServer` returns `{ server, ctx }` with `ctx.config` / `ctx.registry`.
  Internal-API only — no user-facing tool change. `copy` annotation corrected
  `destructiveHint: false → true`.

  adding a future stateful subsystem (add field → construct in createServer →
  destructure in tools → apply #41).
