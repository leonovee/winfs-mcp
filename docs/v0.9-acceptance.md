## What shipped

**No new tools** — the surface stays at **39** (frozen since v0.8). The wave is
protocol support, stabilisation, and a security-audit closeout.

- **MCP Roots protocol support (v0.9.0).** The server now honours client-supplied
  MCP roots, unioned with `config.allowedRoots` through a single `RootsResolver`
  (spec §AC). Hot path and audit both read the resolved union; strict-mode
  enforcement is unchanged.
- **Flaky process-test stabilisation (v0.9.1).** The 10 intermittent
  `tests/unit/process/*` failures were root-caused (ProcessRegistry didn't
  destroy child stdio pipes on settle, so libuv held handles and the tempdir
  `fs.rm` hit EBUSY; the timeout handler didn't force-settle when `taskkill /F /T`
  failed to fire `close`). `ProcessSession.settle` now destroys stdio pipes, the
  timeout handler adds a defensive grace + force-settle, and tempdir removal uses
  a retry ladder.
- **`config.powershellExePath` (v0.9.1).** Explicit PowerShell binary override;
  default auto-detect prefers `pwsh.exe` (PS 7+) and falls back to
  `powershell.exe` (PS 5.1), skipping the Microsoft Store shim.
- **`fetch_url` error-code hardening (v0.9.1).** New `EMAXREDIRECTS`
  (redirect-chain exhaustion) and `EENCODING_UNSUPPORTED` (refuses
  Content-Encoding it can't decode — closes a silent gzip byte-count corruption).
- **Security audit `npm audit` 7 → 0 (v0.9.2).** All 7 advisories (assessed
  0-exposed / dev-only in `audit/security/v0.9.2-triage.md`) were closed anyway:
  vitest 2 → 4 (critical UI-server advisory + 4 transitive moderates), diff
  7 → 9 (low jsdiff DoS, unreachable parse path), qs 6.15.1 → 6.15.2 (moderate
  stringify DoS, unreachable — stdio-only, no express). Residual: **0**.

## Tests + smoke

  brought the 10 previously-excluded `process/*` tests back green; the vitest

  and client-supplied MCP roots, resolved through `RootsResolver`; every
