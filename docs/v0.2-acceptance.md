## Hard invariants reaffirmed in v0.2

All 12 spec §2 invariants from v0.1 still hold. v0.2 adds two more:

- **Both-roots check for mutation tools.** `move` and `copy` must verify
  *both* `src` and `dst` resolve inside `allowedRoots` (pinned by
  `tests/invariants/both_roots.test.ts`).
- **Recursive copy does not follow symlinks outside allowedRoots.** Each
  walked entry is realpath-checked; escapes are skipped and surfaced
  in `files_skipped` + `skipped_paths` (cap 10).

## Open questions for v0.3

- **Cross-volume `move` with opt-in fallback.** Add `allow_cross_volume:
  boolean` argument that, when true, performs `copy + delete` and
  documents that the operation is no longer atomic. Tests would need to
  fake an EXDEV via mock fs or a real second drive.
- **`copy` symlink-skip telemetry.** If a tree has > 10 skipped paths
  the audit log should still record the total count even though the
  response is capped. (Currently the response is the source of truth;
  may evolve.)
