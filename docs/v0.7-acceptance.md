# v0.7 acceptance report

Concise factual closeout for the v0.7 "DC-parity" wave. Full detail lives in

/ §Z / §AA / §AB.

## What shipped

Net tool surface: **30 → 37 (+7)**, landed across three sub-waves plus a tails
sweep, a pre-tag external review wave, a bug-fix wave, and a wire-level smoke
harness.

- **Wave 1 — consumer-agent adds (3 tools):** `ssh_exec` (spawns `ssh.exe`
  directly, no shell; host must resolve via `ssh -G`, raw `user@host`
  rejected), `list_path_dirs` (the sanitized PATH subprocesses inherit),
  `write_json` (atomic JSON write, `.json`-enforced, symmetric to `read_json`).
  Spec §X.
- **Wave 2a — existing-tool improvements:** `edit_file` near-miss diff,
  `grep` pagination, `execute_command` hints. Spec §Y.
- **Wave 2b — process control (4 tools):** `start_process`, `interact`,
  `list_process`, `kill_process`, backed by an in-memory `ProcessRegistry`.
  Lifecycle `running → exited|killed|timed_out|spawn_failed`, TTL-held for late
  reads, SIGKILL drain on SIGINT/SIGTERM. Spec §Z.
- **Wave 2c — architectural closure:** `ToolContext` refactor;
  `register*Tool(server, ctx)` replaces positional `(server, config[, registry])`.
  Spec §AB.
- **Pre-tag bug-fix wave:** fetch_url HTTPS→HTTP downgrade block, full
  `fe80::/10` + IPv4-mapped-IPv6 internal-IP detection, `-EncodedCommand` and
  `rm -r` blocklist-bypass closures (with the verify-then-smoke procedure now in
  CLAUDE.md), AbortSignal threading through `edit_file`/`atomicWriteFile`. Spec §AA.
- **bug #2 (empty stdout) investigation:** does NOT reproduce at the server or
  wire layer on this host; ruled environmental. v0.7.2 added defensive
  PowerShell-wrapper hardening (`-OutputFormat Text`, `-InputFormat None`, UTF-8
  console encoding, `exit $LASTEXITCODE`).

## Key invariants added

- **#38** — every settled process session is reapable (the close event drives
  settlement, not the intent-to-terminate flag).
- **#39 / #40** — process-registry concurrency cap + TTL reap semantics.
- **#41** (wave 2c) — stateful sessions settle by close-event only; generalises
  #38 to every future stateful subsystem (spec §AB.1).
